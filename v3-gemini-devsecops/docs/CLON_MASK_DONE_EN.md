## 🔁 2. Cloning HR_PDB from CDB2 to CDB1

- **🎯 Action:** Attempted to create a cloned PDB in CDB1 using the authorized `CLONE_LINK` database link.
- **⚠️ Issue 2:** The `CREATE PLUGGABLE DATABASE` command encountered error **ORA-65012: Pluggable database HR_PDB already exists**, indicating a stale version from a previous deployment.
- **✅ Resolution:** The duplicate database was identified, properly closed (`CLOSE IMMEDIATE`), and fully dropped including all data files:
  ```sql
  DROP PLUGGABLE DATABASE HR_PDB INCLUDING DATAFILES;
  ```
- **🎯 Action:** After cleaning up the environment, a clean clone was performed:
  ```sql
  CREATE PLUGGABLE DATABASE HR_PDB FROM HR_PDB@CLONE_LINK;
  ```
